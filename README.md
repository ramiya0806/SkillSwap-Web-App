# SkillSwap - Learn. Share. Connect.

SkillSwap is a full-stack web application that helps users exchange skills with each other. Users can add the skills they can teach, choose the skills they want to learn, find suitable learning partners, send skill-swap requests, and communicate through real-time-style chat features.

## 🚀 Features

- User Registration and Login
- Gmail-based Email Validation
- User Profile Management
- Add and Manage Teaching Skills
- Add and Manage Learning Skills
- Skill-Based Partner Matching
- Send, Accept, and Reject Swap Requests
- Accepted Partners
- Notifications
- One-to-One Chat
- Unread Message Count
- Message Seen Status
- Typing Indicator
- Emoji Picker
- Online/Offline Status
- Last Message Preview
- Local Storage Login Persistence
- Logout Functionality
